# 中文字词数据格式

适用于语文教材的生字、词语和成语卡片页面。

## 数据模板

```js
/* ---------- 数据 ---------- */
const DATA = [
  {
    unit: "第一单元",
    lessons: [
      {
        lesson: "第1课《课文标题》",
        words: [
          ["词语一", "cí yǔ yī"],
          ["词语二", "cí yǔ èr"],
          ["成语或短语", "chéng yǔ huò duǎn yǔ"]
        ]
      },
      {
        lesson: "第2课《课文标题》",
        words: [
          ["生字", "shēng zì"],
          ["词语", "cí yǔ"]
        ]
      }
    ]
  },
  {
    unit: "第二单元",
    lessons: [
      {
        lesson: "第3课《课文标题》",
        words: [
          ["词语", "cí yǔ"]
        ]
      }
    ]
  }
];
```

## 字段规则

- `unit`：单元名称，例如 `第一单元`。
- `lesson`：课次和标题，例如 `第1课《邓稼先》`。
- `words`：该课的生字、词语或成语列表。
- 每条字词使用 `["汉字或词语", "拼音"]`。
- 拼音使用小写字母和声调符号，例如 `选聘` 对应 `xuǎn pìn`。
- 多音字按课文中的实际读音标注。
- 轻声不加声调，例如 `包袱` 对应 `bāo fu`。

## 生成提示词

```text
请从教材内容中提取每课的生字、词语和成语，并按照指定的 JavaScript 数据格式输出。

要求：
1. 按单元和课文分组。
2. unit 格式为“第一单元”。
3. lesson 格式为“第1课《课文标题》”。
4. words 中每项格式为 ["汉字或词语", "带声调拼音"]。
5. 拼音使用小写字母和声调符号，例如“选聘”为“xuǎn pìn”。
6. 多音字按照课文中的实际读音标注。
7. 轻声不加声调，例如“包袱”为“bāo fu”。
8. 不要重复收录同一课中的字词。
9. 只输出完整的 const DATA = [...]，不要添加解释或 Markdown 代码标记。
```

> 该结构是 JavaScript 数据，不是严格 JSON，可直接放入现有语文字词卡片页面。
