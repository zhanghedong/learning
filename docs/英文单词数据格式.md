# 英文单词数据格式

适用于英语教材的单词和短语卡片页面。

## 数据模板

```js
/* ---------- 数据 [英文, 中文意思, 词性(短语无)] ---------- */
const DATA = [
  {
    unit: "Unit 1",
    lessons: [
      {
        lesson: "单词",
        words: [
          ["apple", "苹果", "n."],
          ["beautiful", "美丽的；漂亮的", "adj."],
          ["quickly", "迅速地；很快地", "adv."],
          ["study", "学习；研究", "v., n."],
          ["can", "能够；可以", "modal v."]
        ]
      },
      {
        lesson: "短语",
        words: [
          ["go to school", "去上学"],
          ["be good at", "擅长……"],
          ["help sb. with sth.", "帮助某人做某事"]
        ]
      }
    ]
  },
  {
    unit: "Unit 2",
    lessons: [
      {
        lesson: "单词",
        words: [
          ["example", "例子；实例", "n."]
        ]
      },
      {
        lesson: "短语",
        words: [
          ["for example", "例如"]
        ]
      }
    ]
  }
];
```

## 字段规则

- `unit`：教材单元，例如 `Unit 1`。
- `lessons`：固定分为 `单词` 和 `短语` 两组。
- 单词使用 `["英文", "中文释义", "词性"]`。
- 短语使用 `["英文短语", "中文释义"]`，不填写词性。
- 多个词性用英文逗号分隔，例如 `v., n.`。
- 常用词性缩写包括 `n.`、`v.`、`adj.`、`adv.`、`prep.`、`conj.`、`pron.`、`num.` 和 `modal v.`。
- 英式和美式拼写可以使用 `/` 并列，例如 `metre/meter`。
- 多个中文释义使用中文分号 `；` 分隔。
- 语法占位符保留 `sb.`、`sth.`、`one's` 和 `...` 等写法。

## 生成提示词

```text
请提取教材中的英语单词和短语，并按指定的 JavaScript 数据格式输出。

要求：
1. 按 Unit 分组，unit 使用“Unit 1”格式。
2. 每个 Unit 分为“单词”和“短语”两组。
3. 单词格式为 ["英文", "中文释义", "词性"]。
4. 短语格式为 ["英文短语", "中文释义"]，不填写词性。
5. 多个词性用英文逗号分隔，例如 "v., n."。
6. 词性使用 n.、v.、adj.、adv.、prep.、conj.、pron.、num.、modal v. 等缩写。
7. 保留英式/美式拼写，例如 "metre/meter"。
8. 中文有多个释义时使用中文分号“；”分隔。
9. 保留 sb.、sth.、one's 和 ... 等语法占位符。
10. 不要重复收录同一 Unit 中的内容。
11. 只输出完整的 const DATA = [...]，不要添加解释或 Markdown 代码标记。
```

> 该结构是 JavaScript 数据，不是严格 JSON，可直接放入现有英语单词卡片页面。
